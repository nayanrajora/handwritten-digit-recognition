Capstone Overview

About The Project

Comprehensive documentation of the theoretical concepts, dataset, architecture, and technology stack.

The MNIST Benchmark

The Modified National Institute of Standards and Technology (MNIST) dataset is the gold standard benchmark in machine learning computer vision. It contains 70,000 grayscale images of handwritten digits:

  • 60,000 training images and 10,000 test images.
  • Each digit is size-normalized and centered in a fixed-size 28×28 pixel grid.
  • Pixel intensity values range from 0 (black background) to 255 (white stroke).

Why CNN for Digits?

Traditional Multi-Layer Perceptrons (MLPs) discard 2D spatial relationships by flattening images immediately. CNNs solve this by preserving grid topology:

  • Local Receptive Fields: Convolution kernels capture local features (loops, strokes, slants) regardless of location.
  • Weight Sharing: The same kernel slides across the entire image, drastically reducing parameter count.
  • Spatial Invariance: Max-pooling ensures digits are recognized even if slightly shifted or tilted.

Production Preprocessing

Raw canvas drawings differ from MNIST in line width, centering, and scale. Our preprocessing pipeline matches MNIST exact conditions:

  • Grayscale Inversion: Dark stroke on white canvas is converted to bright stroke on dark background.
  • Bounding Box Cropping: Removes empty margins and isolates drawn content.
  • Aspect Ratio Resizing: Digit fits inside a 20×20 box, then padded to 28×28 by center of mass.
